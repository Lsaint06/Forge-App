FORGE 2.0 — PREMIUM ATHLETIC PRODUCT REDESIGN

ROLE AND MISSION

You are acting as a senior product designer, mobile UX architect, React Native engineer, accessibility specialist, and quality-assurance engineer.

Your assignment is to transform the existing FORGE fitness tracking application from a functional developer prototype into a polished, premium athletic mobile experience.

This is a REAL IMPLEMENTATION TASK. Do not stop at producing mockups, recommendations, or a design document. Implement the redesign in the existing application, run tests, and commit working code.

The app already exists. Preserve its functional architecture, data models, business logic, persistence, and implemented features.

Repository: Lsaint06/Forge-App

Existing implementation branch: feat/forge-app

Read and understand the existing source code, README, implementation status, product specification, and tests before changing anything.

Create a dedicated redesign branch based on the latest implementation branch. Do not overwrite the original implementation or merge into main.

PRIMARY OBJECTIVE

FORGE must feel like a premium strength-training application that users would willingly use every day.

Current problems identified through physical iPhone testing:

1. The visual design feels generic, unfinished, and overly dependent on red accents.
2. Screens are excessively text-heavy.
3. Features appear scattered without a clear information hierarchy.
4. The interface lacks meaningful exercise imagery, movement visualization, and distinctive iconography.
5. Important actions compete visually with secondary information.
6. The workout editor displays a React Native VirtualizedLists nesting warning.
7. The overall experience resembles a developer dashboard rather than a professional fitness product.

Solve these problems systematically.

NON-NEGOTIABLE PRESERVATION REQUIREMENTS

* Preserve the existing SQLite database and workout records.
* Do not drop, reset, or silently migrate user data.
* Maintain compatibility with existing exported JSON backups.
* Preserve guest/offline functionality.
* Preserve working workout logging, exercise history, templates, programs, progression, nutrition, measurements, recovery, goals, achievements, and settings.
* Preserve existing authentication and sync interfaces.
* Do not replace working domain logic with placeholders or mock state.
* Do not require Supabase for offline guest usage.
* Preserve Expo Go compatibility unless a necessary dependency makes that impossible; explain any such issue before introducing it.
* Do not silently change the units, calculations, or meaning of recorded workout data.
* Existing tests must continue passing.

DESIGN PHILOSOPHY

Product identity: FORGE.

Personality: powerful, disciplined, refined, athletic, confident, minimal.

Avoid generic gaming aesthetics, excessive neon, random gradients, glowing borders, oversized emojis, and decorative clutter.

The visual design should communicate serious training and quality.

Use restrained color, strong typography, clear visual hierarchy, polished interactions, and meaningful data visualization.

Design for a real iPhone first, while retaining reasonable Android compatibility.

Orange is reserved primarily for high-priority actions, selected states, important progress, and significant achievements.

Do not make every icon, heading, chart, or card orange.

Maintain accessible contrast for text, controls, and disabled states.

Use a deliberate typography hierarchy:

* Display: bold athletic headlines
* Screen title: strong, concise, readable
* Section title: clear and understated
* Body: highly legible
* Supporting information: smaller but readable
* Numeric statistics: prominent and aligned

Use available, properly licensed font assets or reliable system fonts. Do not make a network connection necessary for fonts to render.

INFORMATION ARCHITECTURE

Preserve five main destinations but reorganize them:

HOME
Purpose: answer what the user should do today.

TRAIN
Purpose: start, manage, and complete workouts.

EXPLORE
Purpose: discover exercises and learn movements.

PROGRESS
Purpose: understand improvement over time.

YOU
Purpose: manage personal information, goals, recovery, nutrition, and settings.

Avoid creating additional primary tabs for every feature.

Use contextual navigation, clearly labeled secondary screens, and grouped sections.

HOME REDESIGN

Home must become an attractive training command center.

Suggested hierarchy:

1. Compact personalized greeting and current date.
2. Hero card for today’s scheduled session, or a clear freestyle workout action when no program is scheduled.
3. Weekly training consistency visualization.
4. A small selection of meaningful metrics.
5. One contextual training insight.
6. Recent workout or next planned session.

Make the Start Workout action immediately recognizable.

Do not flood Home with every available metric.

Handle first-time users gracefully with a motivating but concise empty state.

Never fabricate scheduled sessions or achievements.

EXERCISE MEDIA

If generated illustrations are unavailable, implement the UI and asset interfaces with tasteful fallback visuals and document exactly which media still needs to be sourced.

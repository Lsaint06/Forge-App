# FORGE 2 design and execution plan

Preserve schema v1, backups, repository, domain calculations, and optional cloud interfaces. No data migration. System typography renders offline. Dark tokens follow the brief; light mode uses higher-contrast equivalents. Eight-point spacing, 12-point card radii, neutral secondary controls, orange primary actions, semantic success completion.

Home: greeting/date → today's genuine schedule or freestyle/resume → weekly consistency → two metrics → contextual insight → recent session.
Train: active/resume → freestyle → saved templates/programs → history. Workout: persistent timer header, one virtualized exercise list, compact weight/reps, optional advanced fields and exercise controls, rest timer, confirmed completion/deletion.
Explore: visual movement cards, search and existing filters, honest locally rendered muscle illustrations, detailed movement guidance and records. Progress: existing trends and time ranges with shared hierarchy. You: personal, wellness, milestones, account/data. Secondary forms inherit the same design system.

Media is presentation metadata separate from persisted exercises. Original vector muscle illustrations are category diagrams, not demonstrations. Bundled image and licensed HTTPS video interfaces leave existing exercise identifiers intact. No invented video URLs.

Sequence: shared tokens/components and media; workout list/picker and progressive disclosure; Home/Train/Explore/Progress/You; interaction tests and existing suites; native exports; status/preview notes; commit dedicated branch. Physical iPhone, VoiceOver, and live cloud checks require separate testing and will not be claimed.

# REFORGE asset register

Every font, image or graphic added for REFORGE is listed here before it ships. Rules are in [PHASE_7_0_REFORGE_ARCHITECTURE.md §8](../../audits/PHASE_7_0_REFORGE_ARCHITECTURE.md):

- Bundled files only, so FORGE stays offline.
- No AI-generated or unlicensed imagery.
- No text baked into images.
- People only with model releases.

Artwork is registered in code in [artwork.ts](../../../src/components/reforge/artwork.ts). Tests require every code entry to carry a credit and a licence.

| Saira Semi Condensed | ≈ 665 px | 15–20% too wide |

Numbers stay in the system face, as the references draw them.

## Onboarding product visuals (Phase 9.2)

Discover Forge and the brand welcome (Stage A, Emergence: its wall of Forge's screens) show Forge's own screens instead of illustrations. Stage A reuses these nine files and adds none.

- **Source:** every file is a crop of a real Forge screen, captured on the Android emulator from the Phase 9 worktree.
- **Data:** a demo athlete ("Alex", generated by Forge's own data layer) on the FORGE DEV throwaway account. No real person, account or personal data appears.
- **No AI and no added text.**
- **Format:** lossless PNG, 840 px wide, 810 KB together.
- **Decorative only:** hidden from screen readers; each page's headline and sentence carry the meaning.

# Training research

Research notes for Forge's training-program design. The user authorized adding these notes to the repository while keeping application implementation unchanged.

- [Initial review and source register](TRAINING_RESEARCH_REVIEW.md): athlete/coaching approaches, research findings, implications and source-access limits.
- [Continuing research](CONTINUING_RESEARCH.md): subsequent findings, corrections and unresolved questions. Later findings may qualify the initial review.

These documents are research references, not approved requirements or clinical advice. They do not establish that Forge's current generator has been validated or that one program is optimal for every person. Athlete claims, coaching judgments, individual studies, research syntheses and implementation proposals must remain distinguishable.

For future work, read both documents before proposing programming changes. Check the current application code rather than assuming the generator has been updated to match the notes. Preserve workout history, exact schedule-to-workout links, offline storage, browser compatibility and the independent Foundation/Evolution phase references. Do not implement exercise rotation or other later-phase features merely because they are discussed in a source.

Record what was actually accessed: full text/relevant sections, abstract, public official feed, secondary account, or inaccessible. A fetched page or a search snippet is not sufficient verification of its claims. Do not reproduce entire copyrighted articles in this repository.

- [Planner 3 programming audit](PROGRAMMING_AUDIT_2026_10_15.md): confirmed implementation defects, corrections, actual default prescriptions, evidence rationale and verification limits.
- [Programming specification (Planner 8)](PROGRAMMING_SPEC_V2.md): the current, implemented rules. Covers the sources actually reviewed, rule-by-rule evidence and strength of support, the prescription and volume tables, an audit of Planner 7, and before/after weekly programs. This supersedes earlier audits for current behaviour; earlier documents remain as history.

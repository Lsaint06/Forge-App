# FORGE Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline.

**Goal:** Build a usable offline fitness tracker and honestly inventory remaining scope.
**Architecture:** Expo Router UI calls a SQLite repository; pure domain functions calculate all metrics. Optional authenticated Supabase sync operates on durable local records.
**Tech Stack:** Expo, React Native, TypeScript, SQLite, Zustand, Zod, React Hook Form, Reanimated, Supabase.
**Spec:** ../specs/2026-10-14-forge-design.md and ../../PRODUCT_SPEC.txt

## Global Constraints
Guest mode without credentials; no fabricated user records; strict TypeScript; no secrets; iPhone testing without Xcode; explicit incomplete-feature inventory.

## Review Focus
- Interrupted workout writes must remain atomic and resumable.
- Malformed backups must leave existing data intact.
- Duplicate completion must never duplicate volume or achievements.
- Invalid and nonfinite measurements must be rejected.
- Conflicting cloud revisions must preserve local records.
